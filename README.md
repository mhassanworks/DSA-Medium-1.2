# DSA Medium 1.2

A collection of Data Structures and Algorithms (DSA) problem-solving implementations in C++, covering medium-level coding challenges frequently asked in coding interviews, competitive programming, and technical assessments.

This repository contains optimized solutions focused on improving problem-solving skills, algorithmic thinking, and understanding of core DSA concepts.

---

## 🚀 Repository Overview

The repository includes implementations of various medium-level DSA problems related to:

- Arrays
- Strings
- Matrices
- Sliding Window
- Two Pointer Techniques
- Greedy Algorithms
- Searching & Sorting
- Interval Problems
- Dynamic Programming Basics

The solutions are implemented in C++ with an emphasis on clean logic, optimized approaches, and interview-oriented problem solving.

- C++
